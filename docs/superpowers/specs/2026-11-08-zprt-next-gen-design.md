# ZPRT_NEXT_GEN — Design

**Date:** 2026-11-08  
**Status:** Approved (v1.1)  
**Repo:** `Benny4ip/ZPRT_NEXT_GEN`, public, MIT  
**Local path:** `C:\Users\Machine\Documents\ZPRT_NEXT_GEN`  
**Engine:** `Flowseal/zapret-discord-youtube` (MIT, bol-van + Flowseal), локально v1.10.2

## Intent / Why

Сейчас «Запрет» управляется `.bat`-меню: чёрное окно консоли, десятки пресетов, `service.bat` с интерактивным меню. Нужна нормальная русскоязычная графическая оболочка: запустить, выбрать пресет, увидеть статус, проверить связь, свернуть в трей. Движок не переписываем — используем `winws.exe` из upstream.

Отдельная задача оболочки — сделать состояние обхода **видимым и приятным**: пока соединения нет, человек сидит в медитации; когда связь установлена — он взлетает, будто поймал просветление.

## Goals

- **G1.** Один клик: включить/выключить обход, статус и лог — в одном окне.
- **G2.** Все пресеты upstream (`general`, `ALT*`, `EXP`, `FAKE TLS AUTO*`) доступны из сгруппированного списка с понятными русскими названиями.
- **G3.** Проверка связи с Discord/YouTube/Google прямо из приложения.
- **G4.** Трей, автозапуск, тёмная тема, полностью русский интерфейс.
- **G5.** Портативная сборка: распаковал zip — запустил. Движок лежит рядом, в git только исходники.
- **G6.** Ничего не ломает upstream: папка движка остаётся совместимой с оригинальным `service.bat`.
- **G7.** Живая анимация состояния: медитирующий человек → взлёт и «просветление» при установке связи.
- **G8.** Иконка и фирменный стиль: красный бриллиант линиями на чёрном фоне.

## Non-goals

- Замена `service.bat` (установка службы, hosts, замена fake-файлов) — второй этап.
- Свой DPI-движок, свои списки, обход вне `winws`.
- Установщик/MSI, автообновление без ведома пользователя.
- Поддержка Linux/macOS.
- Видеофайлы и сторонние анимационные библиотеки (Lottie и т.п.) — анимация только нативная, на XAML.

## Anti-goals (провал)

- Приложение требует UAC на каждый чих после запуска (один раз при старте — норма).
- При выходе из GUI `winws` остаётся висеть сиротой или, наоборот, убивается чужой процесс.
- Обновление движка затирает пользовательские списки.
- Сборка в git содержит бинарники движка.
- Анимация грузит CPU/GPU в фоне или дёргается при 60 Гц.

## Constraints

- **Лицензия MIT**: обязательны copyright bol-van + Flowseal, текст лицензии, дисклеймер «не связан с авторами».
- **WinDivert** требует администратора и может ловиться антивирусом — предупреждение в README и в «О программе».
- **GitHub у пользователя режется провайдером (504)** — все сетевые функции обязаны иметь запасной путь: открыть страницу релиза в браузере / указать папку вручную.
- В git — только исходники; `engine/`, `bin/`, `obj/`, `*.exe`, `*.dll`, `*.sys` в `.gitignore`.
- Релиз собирается **только вручную** (`workflow_dispatch`), после тестирования и команды пользователя.

## Users

Русскоязычный пользователь Windows 10/11, который уже пользуется «Запретом» или ставит его впервые. Не программист: ему нужны понятные названия пресетов, статус «работает/не работает» и кнопка «Проверить».

## Approaches

- **A. Тонкая оболочка над `.bat`** — быстро, но хрупко: `start /min`, `service.bat`, проверка обновлений внутри `.bat`; управлять процессом и ошибками грязно.
- **B. Нативные пресеты (выбрано)** — при сборке `.bat` конвертируются в `presets.json`; GUI сам запускает `bin\winws.exe`. Полный контроль процесса, логов и ошибок, совместимость с upstream сохраняется.
- **C. Полная замена `service.bat`** — максимум возможностей, но долго и дублирует логику upstream. Оставлено на второй этап.

## Design

### Стек

- **.NET 10 / C# / WPF**, MVVM без тяжёлых фреймворков.
- Трей — `System.Windows.Forms.NotifyIcon` (без сторонних пакетов).
- Манифест `requireAdministrator`.
- Публикация: `self-contained`, `win-x64`, single-file. Размер не критичен.
- Тесты ядра — xUnit.

### Структура решения

```
ZPRT_NEXT_GEN/
  ZprtNextGen.sln
  src/
    ZprtNextGen.App/        # WPF: окно, трей, ViewModels, ресурсы RU, анимация
    ZprtNextGen.Core/       # движок, пресеты, настройки, тесты связи, обновления
  tests/
    ZprtNextGen.Core.Tests/
  tools/
    Import-Presets.ps1      # .bat -> presets.json
    Fetch-Engine.ps1        # локальная сборка: копирует/скачивает движок
  assets/
    icon.svg / icon.ico     # красный бриллиант линиями на чёрном
  presets/presets.json      # сгенерированные пресеты (данные, не бинарники)
  docs/superpowers/specs/   # этот документ
  .github/workflows/build.yml
  LICENSE, README.md, .gitignore
```

### Раскладка релиза

```
ZPRT_NEXT_GEN/
  ZprtNextGen.exe
  presets/presets.json
  engine/
    bin/winws.exe, WinDivert.dll, WinDivert64.sys, cygwin1.dll, *.bin
    lists/*.txt
    utils/               # опционально, для совместимости
```

Движок ищется в `engine\` рядом с exe; путь можно переопределить в настройках.

### Пресеты

Схема `presets.json`:

```json
{
  "version": 1,
  "engine": "Flowseal/zapret-discord-youtube",
  "engineVersion": "1.10.2",
  "groups": [
    { "id": "general", "name": "Обычные" },
    { "id": "faketls", "name": "Fake TLS" },
    { "id": "experimental", "name": "Экспериментальные" }
  ],
  "presets": [
    {
      "id": "general",
      "group": "general",
      "name": "Основной",
      "description": "Базовый пресет: Discord + YouTube + общий список",
      "args": "--wf-tcp=80,443,...,{{GameFilterTCP}} --filter-udp=443 ..."
    }
  ]
}
```

- `{{BIN}}`, `{{LISTS}}` заменяются на абсолютные пути движка.
- `{{GameFilterTCP}}` / `{{GameFilterUDP}}` берутся из настроек: `disabled` → `12` (sentinel upstream), `tcp`/`udp`/`all` → `1024-65535`.
- `Import-Presets.ps1` читает `general*.bat`, склеивает строки с `^`, вырезает `start "..." /min "%BIN%winws.exe"`, подставляет плейсхолдеры. Ошибка парсинга — падение скрипта, а не молчаливый пропуск.
- Группы определяются по имени файла: `general*` → обычные, `*FAKE TLS*` → Fake TLS, `*EXP*` → экспериментальные. Незнакомый файл → группа «Другие», а не игнор.

### Выбор пресета (UI)

Не плоский `ComboBox`, а **сгруппированный контекстный список**: кнопка-«селектор» с текущим пресетом и шевроном, по клику — `ContextMenu`/`Popup` с заголовками групп и пунктами. В пункте: русское имя, мелким шрифтом — исходное имя файла. Справа от селектора — описание выбранного пресета.

- Клавиатура: `↑`/`↓` по пунктам, `Enter` — выбрать, `Esc` — закрыть.
- Группы сворачиваемые (запоминается в настройках), чтобы 20+ пресетов не превращались в простыню.

### Управление процессом

- Старт: `Process.Start` с `UseShellExecute=false`, `CreateNoWindow=true`, редирект stdout/stderr.
- Статус: жив ли процесс + совпадение PID, который запустили мы. Чужой `winws` (из `.bat`/службы) показывается как «запущен извне» и не убивается без подтверждения.
- Стоп: `Kill(entireProcessTree: true)` только для своего PID.
- При выходе из приложения — вопрос «остановить обход?» (по умолчанию остановить).

### Интерфейс (RU)

Одно окно, тёмная тема, чёрный фон, красный акцент:

- **Hero-панель (верх):** анимация «Медитация» + статус-пилюля («Работает» / «Остановлен» / «Ошибка») + большая кнопка Вкл/Выкл.
- **Пресет:** сгруппированный контекстный список + описание + кнопка «Проверить связь».
- **Тест связи:** строки Discord / YouTube / Google с ✓/✗ и временем ответа.
- **Лог:** хвост вывода `winws`, кнопка «Открыть папку логов».
- **Настройки:** папка движка, game filter, автозапуск, «сворачивать в трей», тема, «уменьшить анимацию».
- **О программе:** версии, лицензия, ссылки на upstream, дисклеймер.

Трей: Вкл/Выкл, Открыть, Выход. Двойной клик — показать окно.

### Анимация состояния «Медитация»

**Стиль:** линейная графика в духе иконки — красные и белые линии на чёрном, без растровых кадров. Всё рисуется в XAML (`Canvas` + `Path` + `Storyboard`), масштабируется без потерь, не требует внешних файлов и библиотек.

**Фигура:** человек в позе лотоса — голова (круг), торс, скрещённые ноги, руки на коленях. Контур красный, внутренняя линия — приглушённый белый. За спиной — ромб (отсылка к иконке), который играет роль ауры.

**Состояния:**

| Состояние | Анимация |
|---|---|
| **Остановлен** | Медленное «дыхание» (вертикальное смещение 2–3 px, цикл ~4 с), аура тусклая, ромб едва светится |
| **Подключение** | Пульсирующее красное кольцо вокруг фигуры, дыхание чаще, аура разгорается |
| **Работает (связь есть)** | Фигура плавно взлетает на 20–25% высоты (ease-out, ~1.2 с), аура вспыхивает и меняет цвет с красного на золотисто-белый, из-за спины раскрываются 8–12 лучей и медленно вращаются, вверх поднимаются частицы-ромбики и растворяются, фигура мягко покачивается в воздухе |
| **Ошибка** | Красная вспышка, аура схлопывается, фигура опускается обратно |

**Реализация:**

- `Storyboard` на `TranslateTransform`, `ScaleTransform`, `RotateTransform`, `Opacity` и `ColorAnimation` — только GPU-дружественные свойства, без пофреймового кода.
- Частицы — 10–14 `Path`-ромбиков с разными задержками; переиспользуются, а не создаются каждый цикл.
- Переходы между состояниями — `BeginStoryboard` с `HandoffBehavior.SnapshotAndReplace`, чтобы не было рывков.
- Настройка «уменьшить анимацию» (по умолчанию выключена) отключает частицы и оставляет только смену цвета/статуса — для слабых машин и чувствительных к движению.
- Анимация не запускается, когда окно свёрнуто в трей.

**Где живёт:** `src/ZprtNextGen.App/Controls/MeditationView.xaml` + `MeditationState` в VM. Состояния: `Stopped`, `Connecting`, `Connected`, `Error`.

### Иконка и фирменный стиль

- **Иконка:** красный бриллиант, нарисованный линиями (контур + внутренние грани), на чёрном фоне. Авторская SVG-геометрия, конвертация в `.ico` (16–256 px) на сборке.
- **Палитра:** фон `#0A0A0A`, поверхности `#141414`, акцент `#E01B2E`, акцент-свечение `#FF3B4E`, текст `#EDEDED`, вторичный текст `#8A8A8A`. Золотистый (`#FFC65C`) — только для «просветления» в анимации.
- **Шрифт:** системный `Segoe UI Variable` с фолбэком на `Segoe UI`.

### Настройки

`%APPDATA%\ZPRT_NEXT_GEN\settings.json`: `enginePath`, `presetId`, `collapsedGroups`, `gameFilter`, `autostart`, `minimizeToTray`, `theme`, `reduceMotion`.

Автозапуск — задача планировщика с наивысшими правами (без UAC-окна), создаётся/удаляется по тумблеру. По умолчанию выключен.

### Сеть и обновления

- **Тест связи:** параллельные HTTPS-запросы (5 с таймаут) к `discord.com`, `gateway.discord.gg`, `www.youtube.com`, `redirector.googlevideo.com`. Результат — таблица.
- **Проверка обновлений движка:** GitHub API `Flowseal/zapret-discord-youtube` → сравнить тег с `engineVersion`. Скачивание zip — с таймаутом; при 504/ошибке — кнопка «Открыть страницу релиза» и «Указать папку вручную».
- **Обновление списков:** скачивание `list-general.txt`, `ipset-all.txt` и user-файлов; перед заменой — бэкап в `engine\lists\backup\`.
- Обновления никогда не затирают `*-user.txt`.

### Логи и ошибки

- Лог приложения: `%APPDATA%\ZPRT_NEXT_GEN\logs\app-YYYYMMDD.log`.
- Ошибки запуска (нет `winws.exe`, нет `WinDivert64.sys`, отказ драйвера) — человеческим текстом + ссылка на README-раздел.

## Risks

| Риск | Митигация |
|---|---|
| WinDivert ловится антивирусом | предупреждение в README/UI, хэши движка, ссылка на upstream |
| GitHub 504 у пользователя | ручной путь: браузер/локальная папка |
| Upstream меняет формат `.bat` | `Import-Presets.ps1` падает явно; пресеты версионируются |
| Приложение убивает чужой `winws` | сравнение PID, подтверждение |
| Автозапуск с правами админа пугает | выключен по умолчанию, объяснение в UI |
| Анимация ест ресурсы | GPU-свойства, переиспользуемые частицы, пауза в трее, «уменьшить анимацию» |

## Definition of Done

- Публичный репозиторий с исходниками, MIT, README и CI.
- GUI собирается, запускается от админа, стартует/останавливает `winws` с выбранным пресетом.
- Все пресеты upstream доступны, сгруппированы и корректно конвертированы.
- Тест связи и трей работают; настройки сохраняются.
- Анимация «Медитация» отрабатывает все четыре состояния, не грузит систему, отключается в трее.
- Иконка — красный бриллиант линиями на чёрном.
- Движка нет в git; релизный zip собирается вручную.
- Проверено на этой машине: обход Discord/YouTube работает, `winws` не остаётся сиротой.
